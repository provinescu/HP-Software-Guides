# HP Software Guides

> **Provinescu Software Production**  
> Documentation for the Provinescu collection of SuperCollider classes and standalone generative-music applications.

**SuperCollider 3.14 · Generative Music · Sound Organization · Wekinator · HPtransformer**

This repository contains user guides for the HP Software collection. The documentation covers installation, first launch, configuration, working folders, sound libraries, and application-specific workflows.

## Documentation collections

| Collection | Description | Repository |
|---|---|---|
| **HP Silicon Standalone** | Guides for standalone applications for Macs with Apple silicon | [Open the repository](https://github.com/provinescu/HP-Silicon-Standalone) |
| **Software Classes** | Guides for the SuperCollider source-class editions | [Open the repository](https://github.com/provinescu/Software-Class) |

## Topics covered

Depending on the application and edition, the guides may cover:

- installation and first launch;
- MIDI and audio configuration;
- creation and management of working folders;
- presets, application data, and sound lists;
- custom sound libraries;
- Wekinator and OSC configuration;
- HPtransformer learning and generation;
- real-time monitoring and performance settings;
- troubleshooting and diagnostic messages.

## Available editions

| Edition | Typical name | Wekinator | HPtransformer | Main function |
|---|---|:---:|:---:|---|
| **Standard** | `Agents` | No | No | Standard functionality |
| **Wek** | `WekAgents` | Yes | No | Parameter control via Wekinator |
| **TR** | `AgentsTR` | No | Yes | Learning and generation with HPtransformer |
| **Wek+TR** | `WekAgentsTR` | Yes | Yes | Combines Wekinator and HPtransformer |

## Recommended reading order

1. Open the guide for the application you want to use.
2. Follow the installation and MIDI setup instructions.
3. Create or select a working folder.
4. Test the Standard edition with its default configuration.
5. Read the custom-sound instructions before editing a `sound` or `list sound` file.
6. Continue with the Wekinator or HPtransformer sections when using a Wek, TR, or Wek+TR edition.
